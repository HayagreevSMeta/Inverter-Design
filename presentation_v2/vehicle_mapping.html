Vehicle Architecture Mapping

Drivetrain parameters dictate the operating points: G = 8.19 gear ratio, r = 0.315m tyre radius, p = 4 pole pairs.
Electrical frequency (fe) is directly proportional to vehicle speed (v):
fe = (v/r) × (G/2π) × p
Using an RL load model (R = 1.3Ω, L = 2mH), current decreases with speed as load impedance increases.
Urban (40 km/h): fe = 184 Hz, Ipk = 136A — highest thermal stress.
Highway (120 km/h): fe = 552 Hz, Ipk = 51A — lowest loss but highest frequency demand.
